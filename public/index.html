 Hướng dẫn sử dụng

      

        

        

          

            
Bắt đầu

            
    
              
  1. Bấm Thêm dự án (góc phải trên) và dán đường dẫn một repo git, ví dụ D:\CPLUS\ADMIN\ris_admin_v1.
    2. 
              
  2. Ở sidebar, rê chuột vào một nhánh rồi bấm ▶ để mở phiên Claude mới.
    3. 
              
  3. Gõ yêu cầu vào terminal như khi dùng Claude Code bình thường.
    4. 
              
  4. Bấm Bật thông báo một lần để nhận thông báo khi Claude cần bạn hoặc làm xong.
    5. 
            

            
Giữ cửa sổ dòng lệnh đang chạy claude-hub mở. Đóng nó thì mọi phiên và terminal trong hub đều dừng.

          

          

            
Dự án, nhánh và workspace

            
    
              
  • Sidebar nhóm theo dự án → nhánh/worktree → phiên.
    • 
              
  • Nút ▶ trên đầu dự án mở phiên ở thư mục gốc của dự án; nút ▶ trên từng nhánh mở phiên ở thư mục của nhánh đó.
    • 
              
  • Thêm một thư mục cha chứa nhiều repo thì hub thêm từng repo và tạo một workspace cho chính thư mục cha. Bấm Toàn bộ workspace để một phiên Claude làm việc trên tất cả repo con.
    • 
              
  • Trang của nhánh có nút tạo worktree/nhánh mới, mở Terminal, lazygit, Thư mục và danh sách file đã sửa.
    • 
            

          

          

            
Phiên Claude

            
Trạng thái hiện bằng chấm màu ở sidebar và trên trang Tổng quan:

            
    
              
  • Sẵn sàng: đang chờ bạn gõ yêu cầu.
    • 
              
  • Đang chạy: Claude đang làm việc.
    • 
              
  • Chờ bạn: Claude hỏi hoặc xin quyền; câu hỏi hiện ngay trên Tổng quan.
    • 
              
  • Xong: đã trả lời xong, bạn chưa xem.
    • 
              
  • Đã thoát: tiến trình Claude đã dừng.
    • 
            

            
Các nút trên thanh của phiên:

            
    
              
  • Terminal: mở shell tại thư mục của phiên.
    • 
              
  • MCP và Skill: chọn MCP server, plugin và skill cho riêng phiên này (xem bên dưới).
    • 
              
  • Tệp: mở text editor. File đã sửa: danh sách file thay đổi, bấm để xem diff.
    • 
              
  • Dừng dừng tiến trình Claude. Đóng phiên dừng và bỏ phiên khỏi hub; cuộc trò chuyện vẫn còn trong lịch sử.
    • 
            

            
Kéo chuột lên trong terminal để xem lại toàn bộ phiên. Hub mở Claude ở giao diện cổ điển nên cuộn được hết (tối đa 1 triệu dòng); đổi trong Cài đặt → Phiên Claude. Nếu chọn Fullscreen, Claude chỉ vẽ một đoạn gần nhất, bấm Ctrl+O để xem toàn bộ.

          

          

            
Sao chép và dán

            
Dùng được trong cả phiên Claude lẫn terminal popup:

            
    
              
  • Bôi đen bằng chuột rồi bấm Ctrl+C để sao chép. Không bôi đen gì thì Ctrl+C vẫn là lệnh ngắt như thường (dừng Claude hoặc dừng lệnh đang chạy).
    • 
              
  • Ctrl+Shift+C hoặc Ctrl+Insert: luôn chỉ sao chép, không bao giờ ngắt.
    • 
              
  • Ctrl+V, Ctrl+Shift+V hoặc Shift+Insert: dán.
    • 
            

          

          

            
Lịch sử phiên

            
    
              
  • Trang của nhánh có mục Lịch sử phiên: mọi cuộc trò chuyện Claude Code đã lưu cho thư mục đó, kể cả phiên mở ngoài hub (VS Code, CLI).
    • 
              
  • Bấm Mở lại để tiếp tục đúng cuộc trò chuyện đó (claude --resume). Ô lọc giúp tìm theo nội dung câu hỏi.
    • 
              
  • Đừng mở cùng một cuộc trò chuyện ở hai nơi cùng lúc, lịch sử dễ bị rối.
    • 
            

          

          

            
MCP theo phiên

            
    
              
  • Bấm MCP trên thanh phiên để xem các MCP server phiên đang dùng và số lần đã gọi.
    • 
              
  • Bỏ tick những MCP không cần, bấm Áp dụng & khởi động lại. Phiên mở lại và giữ cuộc trò chuyện.
    • 
              
  • Kiểm tra kết nối chạy thử từng MCP; rê chuột vào chữ “lỗi” để xem lý do.
    • 
            

          

          

            
Skill và plugin theo phiên

            
Mỗi phiên luôn nạp sẵn tên và mô tả ngắn của mọi skill; nội dung đầy đủ chỉ nạp khi skill được gọi. Nhiều skill chồng chéo dễ làm Claude chọn nhầm, nên tắt bớt những gì phiên không cần.

            
    
              
  • Bấm Skill trên thanh phiên. Dòng đầu cho biết phiên đang có bao nhiêu skill và tốn khoảng bao nhiêu token mô tả.
    • 
              
  • Tick ở đầu plugin: bật/tắt cả plugin. Tắt plugin thì Claude không còn thấy nó, kể cả hook của plugin.
    • 
              
  • Bấm mũi tên để xổ danh sách skill trong plugin. Bỏ tick một skill thì Claude bị chặn gọi skill đó, nhưng tên vẫn nằm trong danh sách.
    • 
              
  • Skill riêng (~/.claude/skills, .claude/skills của repo): bỏ tick là bỏ hẳn khỏi ngữ cảnh.
    • 
              
  • Chỉ áp dụng cho phiên đó, không đổi cấu hình Claude Code chung. Bấm Về mặc định để quay lại như cũ.
    • 
            

            
Ví dụ: phiên sửa API .NET thì tắt plugin thiết kế giao diện; phiên làm frontend thì bật lại.

          

          

            
Terminal popup

            
    
              
  • Nút Terminal mở popup shell tại thư mục đang xem. Mặc định là PowerShell; chọn cmd hoặc Git Bash ở ô chọn trên đầu popup, hoặc đổi mặc định trong Cài đặt.
    • 
              
  • Mở được nhiều tab. Kéo thanh tiêu đề để di chuyển, kéo góc để đổi kích thước. Nút thu nhỏ đưa popup xuống góc màn hình, shell vẫn chạy.
    • 
            

          

          

            
Text editor

            
    
              
  • Nút Tệp mở cây thư mục của dự án/workspace; bấm file để mở thành tab.
    • 
              
  • Ctrl+S lưu, Ctrl+F tìm, Shift+Ctrl+F thay thế, Alt+G nhảy tới dòng, Ctrl+/ comment.
    • 
              
  • Nếu file vừa bị sửa bên ngoài (ví dụ Claude vừa sửa), hub hỏi trước khi ghi đè.
    • 
              
  • Editor nhẹ, không có IntelliSense/debug; việc đó vẫn dùng VS Code.
    • 
            

          

          

            
Git

            
    
              
  • Trang của nhánh có Lịch sử git dạng cây: màu theo nhánh, nhãn nhánh/tag/remote. Có thể xem cả các nhánh khác và lọc theo nội dung hoặc tác giả.
    • 
              
  • Bấm một commit để xem file đổi và diff; từ diff bấm Mở trong editor.
    • 
              
  • Hub chỉ xem, không commit/push. Muốn thao tác thì dùng lazygit hoặc Terminal.
    • 
            

          

          

            
Đặt tên

            
Bấm nút bút chì trên dòng tương ứng ở sidebar để đặt tên cho dự án, thư mục worktree, workspace hoặc phiên. Để trống thì dùng lại tên gốc. Hai thư mục trùng tên (ví dụ hai bản clone cùng repo) tự được phân biệt.

          

          

            
Cài đặt

            
Nút Cài đặt (góc phải trên): bộ màu, màu tự chọn, độ vát góc, cỡ chữ, độ rộng sidebar, font terminal, shell mặc định, âm thanh báo, CSS tùy chỉnh. Có nút xuất/nhập để mang cấu hình sang máy khác.

          

          

            
Xử lý sự cố

            
    
              
  • Phiên không đổi trạng thái: kiểm tra hub còn chạy. Phiên mở ngoài hub không có trạng thái.
    • 
              
  • “đang kết nối…” ở thanh trên: hub đã tắt hoặc vừa khởi động lại; chạy lại claude-hub rồi tải lại trang.
    • 
              
  • Không tìm thấy claude: đặt biến CLAUDE_HUB_CLAUDE trỏ tới file chạy của Claude Code.
    • 
              
  • Cổng 4317 bận: chạy claude-hub --port 4400.
    • 
              
  • MCP báo lỗi: thường do dịch vụ phía sau (ví dụ database) chưa chạy, hoặc cấu hình trong ~/.claude.json sai.
    •
